# Mi repositorio de práctica

Este repositorio fue creado como parte de una actividad para aprender a utilizar Git y GitHub, practicar el manejo de archivos y llevar un registro de los cambios realizados mediante commits.

## 📁 Contenido del repositorio

- **receta.md:** Contiene mi receta favorita, sus ingredientes y pasos de preparación.
- **historia.md:** Explica el origen del arroz con pollo y por qué me gusta esta receta.
- **metas.md:** Contiene mis metas personales y académicas para este trimestre.

## 🎯 Objetivos

- Aprender a utilizar Git y GitHub.
- Practicar la creación y edición de archivos Markdown.
- Aprender a realizar commits con mensajes claros.
- Llevar un registro de los cambios realizados en el repositorio.
- Organizar mis trabajos y actividades.

## 🛠️ Herramientas utilizadas

- Git
- GitHub
- Markdown
- Visual Studio Code
